Keterangan Kolom
Definisi field per Pasal 4 Ayat 2 — SLA Response Time
Problem Time — waktu problem dilaporkan oleh requestor.
Response Time — waktu engineer pertama kali respond / acknowledge problem.
Max Response — durasi dari Problem Time ke Response Time (jam:menit).
Restoration Time — waktu sistem kembali beroperasi (workaround / partial fix).
Restoration Action — tindakan untuk mengembalikan operasional sementara.
Resolution Time — waktu problem benar-benar terselesaikan (root cause).
Δ Resolution — durasi total dari Problem Time ke Resolution Time.
Resolution Action — tindakan akhir / deliverable ke requestor.
