Root Cause & Solusi

Baris 271–275 di stock_picking.py melakukan string concatenation str(accounting_date_po) + ' ' + str(date_approved.time()) yang menghasilkan microsecond di akhir string — tidak kompatibel dengan DATETIME_FORMAT Odoo. Deploy fix ke staging DSN, test alur approval retur secara penuh, lalu push ke production.
